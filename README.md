# DBMS Assignment 3 – SQL Programming

## Overview
This assignment contains SQL queries based on the Student and Department database using MySQL.

## Files
- `Assignment_3_CollegeDB.sql` – Contains SQL programs for Questions 1 to 10.
- `README.md` – Contains assignment details and instructions.

### 2. Student

4. UPDATE and DELETE

7. SQL JOINs
8. Subqueries

## Software Used
- MySQL
- MySQL Workbench

## How to Run
1. Open MySQL Workbench.
2. Open the `Assignment_3_CollegeDB.sql` file.
3. Run Question 1 to create the database and tables.
4. Run Question 2 to insert the records.
5. Execute the remaining queries question-wise.

## Important Notes
- Run INSERT statements only once to avoid duplicate records.
- UPDATE and DELETE commands modify the existing data.
- Follow the instructions in the SQL file before running Question 10.

## Conclusion
This assignment provides practice in basic SQL commands, data filtering, aggregate functions, joins, subqueries, and database operations using MySQL.
